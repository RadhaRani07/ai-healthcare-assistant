# AI Healthcare Assistant

An educational machine learning project that uses Python and Scikit-learn to classify diabetes outcomes from medical dataset features.


## 🚀 Live Demo

Try the app here: [AI Healthcare Assistant](https://ai-healthcare-assistant-rcvk82rkkgaqtpo6vgxjhr.streamlit.app/)


## Project Overview

This project demonstrates a basic machine learning workflow, including data preprocessing, model training, evaluation, and an interactive web interface built with Gradio.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Gradio
* Google Colab

## Machine Learning Model

* **Algorithm:** Logistic Regression
* **Dataset:** Diabetes dataset containing 768 records and 9 columns
* **Data split:** 80% training and 20% testing
* **Accuracy:** Approximately 70.78%

## Model Evaluation

The model was evaluated using accuracy, a confusion matrix, precision, recall, and F1-score.

The current results show that the model has limitations, particularly in identifying the diabetes class. Further experimentation is needed to improve its performance.

## Interactive Demo

The project includes a Gradio interface that accepts the eight input features and displays the model's predicted category.

## Disclaimer

This project is for educational purposes only. It is not a medical diagnosis tool and must not be used to make medical decisions.
